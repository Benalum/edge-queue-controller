# Sol companion clips

This directory is reserved for built-in Sol companion media.

The R16BV source stage tries to reconcile these public static files from the live site when available:

- dog_listening_236b385d.mp4
- dog_thinking_8dcd159e.mp4
- dog_talking_f28d314b.mp4

If those files are not present locally, the Sol preset still appears and the UI falls back to a safe placeholder instead of requiring users to provide their own media.
