## Recommendation

EP_RECOMMENDATION=prefer_candidate_c_then_candidate_b_as_fallback

Preferred path:
1. Design a dedicated automation identity/tag/device path.
2. Avoid root if feasible.
3. Keep LAN TCP22 closed.
4. Keep current human/admin check-mode behavior separate from automation path.
5. Require explicit Tailscale admin-console approval before applying any policy.
6. Require a rollback plan and post-change read-only validation before worker/runtime activation.
