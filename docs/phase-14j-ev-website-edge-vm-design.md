## Scope

MUTATION_SCOPE=docs_smoke_only_website_vm_design

This phase designs the website-edge VM for the low-power Proxmox host. It creates no VM/container, makes no Cloudflare change, makes no Tailscale ACL/grants/tag change, changes no firewall, restarts no services, starts no workers, activates no runtime behavior, and mutates no production DB/jobs.
