# Stage 5O-28 Public Summaries Without Body Auth Buttons — 2026-06-11

## Result

Removed page-body login/create-account buttons from public logged-out feature summaries.

## Design rule

The header owns authentication actions.

Public page bodies should only explain what the page does and look polished.

## Expected behavior

Logged-out feature pages show:

- a clean page summary
- feature cards
- no body-level login/create-account buttons

Logged-in users still see the usable feature pages.
