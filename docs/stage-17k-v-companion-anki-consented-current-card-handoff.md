# Stage 17K-V — Companion Anki Consented Current-Card Handoff\n\nDate: 2026-06-28\n\n## Summary\n\nStage 17K-V adds a browser-only consent command for the current in-memory Anki card.\n\nThe default Companion bridge path remains shape-only.\n\nAnki question and answer text are returned only when `consentedCurrentAnkiCardForStudyCommand(true)` is called or when the user clicks the explicit consent button.\n\n## Source changes\n\n- Adds `consentedCurrentAnkiCardForStudyCommand(consented)`.\n- Adds a Companion button: `Use current Anki card in Companion study`.\n- Adds a consent output area that reports status without printing card text into the page.\n- Exports the consented command on `window.APC_COMPANION_LOCAL_ANKI_BRIDGE`.\n- Cache-busts `companion-local-anki-bridge.js`.\n\n## Required behavior\n\nPre-consent command behavior:\n\n- `consented: false`\n- no `question` field\n- no `answer` field\n- shape and lengths only\n- no backend call\n- no model call\n- no Anki write\n\nPost-consent command behavior:\n\n- `consented: true` when a current card exists\n- `card.question` exists only in the immediate browser command result\n- `card.answer` exists only in the immediate browser command result\n- `card_text_persisted: false`\n- no backend call\n- no model call\n- no Anki write\n- no MyDecks writeback\n\n## Safety\n\nNo backend deploy, DB write, Anki write, Google Drive write, file upload, card import, media copy, model call, worker activation, scheduler activation, service restart, nginx mutation, or cloudflared mutation is included.\n\nNo Anki question text or answer text is saved to repo docs.\n
