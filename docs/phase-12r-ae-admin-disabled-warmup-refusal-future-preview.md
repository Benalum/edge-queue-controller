# Phase 12R-AE Admin Disabled Warmup Refusal Future Preview

Phase 12R-AE enriches the disabled admin model warmup refusal with a read-only future warmup execution preview.

## Purpose

When a valid admin calls:

- `POST /admin/model-warmup`

the endpoint still returns HTTP 403 because warmup execution is disabled. The disabled refusal now includes:

- `future_warmup_execution_preview`

This preview is generated by:

- `_stage5p12y_disabled_future_warmup_execution_skeleton(...)`

## Safety

This phase must not:

- Start persistent lane workers.
- Enable router rollout.
- Enable warmup execution.
- Call `/api/generate`.
- Call `/api/chat`.
- Warm any model.
- Unload any model.

## Expected behavior

The route remains admin-auth bounded.

The route may call read-only model memory status to build the preview. It must still return HTTP 403 and must not execute warmup.

The preview must remain non-executable:

- `runtime_action_available: false`
- `would_call: none`
- `future_ollama_request.execute_now: false`
- `reason: runtime_action_unavailable`
