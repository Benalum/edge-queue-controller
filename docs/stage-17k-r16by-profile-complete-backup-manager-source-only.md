# stage-17k-r16by-profile-complete-backup-manager-source-only

Source-only stage. No deploy, no SSH, no sudo, and no live site change.

## Purpose

Add a simple Profile backup manager for the local-first app so users do not have to rely on the older preview-only current-backup diagnostics.

## User-facing behavior

- Adds a **Complete local backup** panel in Profile.
- Adds **Preview current browser data**.
- Adds **Download buddies-who-study-current.json**.
- Adds **Open backup file details**.
- Intercepts the older **Open current backup file** button and routes it to the new readable backup detail preview.
- Hides noisy preview-only save-plan diagnostics by default.

## Coverage shown in the new preview

- Deck names.
- Card list and front/back image coverage.
- Session count and study totals.
- Companion name/display-name settings.
- Custom companion clip/media counts.
- Local media blob counts and bytes.
- Backup document keys.
- Anki policy: Anki source files are read-only; Buddies progress is saved locally only.

## Safety

- Browser-local only.
- No backend upload.
- No Google Drive sync activation.
- No Anki source write.
- No restore or merge operation.
- Download is a new JSON file generated by the browser.
